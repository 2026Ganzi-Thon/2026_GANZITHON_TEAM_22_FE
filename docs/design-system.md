# 디자인 시스템

> 출처: 피그마 `간지톤` 파일 (HM-01 홈, 컬러·텍스트 프레임). 2026-11-07 기준.
> 코드에서는 이 값을 `src/constants/theme.ts`로 옮겨 쓰고, 화면에 hex를 직접 쓰지 않는다.
> 기준 화면 크기: **402 × 874** (iPhone 16 Pro)

## 브랜드

| 항목 | 값 |
| --- | --- |
| 서비스명 | 마음쉼 TASK |
| 앱 로고 | `haebo` (한글 표기 "해보양") |
| 캐릭터 묶음 | 감정콩 / 이모양즈 |
| 캐릭터 | 화남이(빨간 꽃), 슬픔이(파란 귀), 기쁨이 |

## 에셋 (피그마 "이미지 소스")

- 앱 아이콘: `haebo` 3색(옐로·핑크·블루)
- 로고 워드마크: `haebo` 옐로·핑크
- 캐릭터: 단체 이미지, 개별 표정, 프로필 원형 이미지
- 배경: 무지개 구름, 벚꽃 피크닉, 밤하늘 달, 서재, 카페
- 스터디룸: 캐릭터별 공부 컷 / 쉬는 컷
- 3D 아이콘: 하단 탭(홈·할 일·감정콩·내 정보), 스터디룸 하단(할 일·대화·나가기), 기타 UI 아이콘
- 선 아이콘: Flaticon UIcons(`fi-rr-plus`, `fi-rr-angle-small-right`, `fi-rr-pause`)
- 스플래시: 스플래시 화면 이미지 (피그마 "앱 들어가면 잠깐 나오는 페이지")
- 파비콘(웹 탭 아이콘): `haebo` 앱 아이콘 옐로
