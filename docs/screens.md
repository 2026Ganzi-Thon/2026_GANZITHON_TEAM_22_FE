## IA

```
로그인 → 마음쉼 TASK
├─ 홈: 할 일 미리보기·추가·상세 / 다음 시작 알림 안내·변경·취소 / 함께 시작하기
│   └─ 함께 시작하기 → 할 일 선택(미선택 가능) → 스터디룸
│       └─ 스터디룸: 할 일 체크 / 대화 / 타이머(공부·휴식) / 나가기
│           └─ 나가기: 이따 다시 할게(→ 다음 시작 알림) / 오늘은 여기까지(→ 홈) / 계속하기
├─ 할 일: 전체 목록 / 등록·수정 / 상세(세부 할 일)
├─ 감정콩: 단체 대화방
└─ 내 정보: 프로필 / 알림 ON/OFF
```

## 공통

- 하단 탭 4개: `홈 / 할 일 / 감정콩 / 내 정보` (3D 아이콘, 선택 탭 뒤에 은은한 glow)
- 상세·수정 화면 헤더: `< 이전 화면명` + 우측 액션(연필 / `완료` / `삭제`)
- 할 일 카드: 체크 원 + 제목 + 보조 문구 + D-day 배지
- 세부 할 일 행: 체크 원 + 이름 (수정 모드에서는 우측 `–` 삭제)
- 날짜·시간 선택 시트: 월 달력 + `오전/오후 · 시 : 분` + 선택 요약 + 확인 버튼 (HM-02-add 마감 날짜, ST-04 직접 설정에서 공통 사용)
- 확인 다이얼로그: 문구 + `예 / 아니오`

## HM — 홈

### HM-01 홈
- 상단: `haebo` 로고, 캐릭터 3명 배경, 말풍선 + `예약 변경` 배지
- `나의 할 일` 카드: + 버튼, 할 일 목록, `함께 시작하기`
- 하단 탭

| 누르는 곳 | 동작 |
| --- | --- |
| 왼쪽 동그라미 | 완료 체크 / 취소 |
| 나머지 카드 영역 | HM-02-detail |
| + | HM-02-add |
| 함께 시작하기 | ST-01 |
| 말풍선 `예약 변경` | HM-02-alarm |

| 할 일 상태 | 제목 아래 표시 | 예시 |
| --- | --- | --- |
| 마감일 있음 | 마감일 | `10/30 23:59` |
| 마감일 없음 + 세부 할 일 있음 | 미완료 세부 할 일 중 첫 번째 | `1과 개념 정리` |
| 둘 다 없음 | 생략 (제목만) | |

| 알림 상태 | 감정콩 말풍선 | 예시 |
| --- | --- | --- |
| 알림 없음 | 반겨주는 문구 생성 | 안 그래도 너 얘기하고 있었는데 ㅋㅋㅋ |
| 알림 있음 | 다시 만나기로 한 시간 | 오늘 오후 8시에 다시 만나기로 했어 |

### HM-02-add 할 일 추가
- 헤더: `< 홈` + `완료`
- `새로운 할 일` — "할 일을 입력해줘."
- `마감 날짜 (선택)` — "마감 날짜가 언제야?" → 날짜·시간 시트(`마감 날짜 선택`)
- `세부 할 일 (선택)` — "일을 작게 쪼개보자!" + 점선 `+` 추가

### HM-02-detail 할 일 자세히 보기
- 헤더: `< 홈` + 연필 + `완료`
- 할 일(우측 등록 일시) + D-day, 세부 할 일 목록

### HM-03-done 할 일 추가 완료 / HM-03-edit 수정하기
- done 헤더: `< 홈` + 연필 + `삭제` / edit 헤더: `< 홈` + `완료`
- 할 일, 마감 날짜, 세부 할 일(edit에서 `–` 삭제)
- 삭제 확인: "할 일을 삭제해볼까?" `예 / 아니오`

### HM-02-alarm 알림 변경하기
- 헤더: `< 홈`
- `다시 하기 알림` + 연필, 예약 일시 행 + `–`(취소)

## ST — 함께 시작·스터디룸

### ST-01 함께 시작하기
- 상단: `마음쉼` + "일단 펼쳐볼까? 우리도 같이 할게" + 캐릭터
- 하단 카드 `뭐부터 같이 할까?`: 할 일 목록(D-day), `바로 시작하자!`, `선택 없이 시작하자!`
- 선택된 항목은 채워진 원으로 표시

### ST-02 스터디룸
- 헤더: 할 일 이름 + "같이 공부하는 중...", 타이머 pill(`Ⅱ 00:06:13`)
- 2×2 그리드: 화남이 / 슬픔이 / 기쁨이 / 나(카메라 OFF 시 "카메라가 꺼져있어요")
- 하단: `할 일 / 대화 / 나가기`
- 쉬는 중: 타이머 자리 `▶ 다시 시작`, 캐릭터 쉬는 컷 + 말풍선("좀 쉬자...", "제발ㅠㅠ", "그럴까??")

| 버튼 | 나오는 화면 | 내용 |
| --- | --- | --- |
| 할 일 | ST-03-todo (전체 화면) | 선택한 할 일, 세부 할 일 체크, `< 스터디룸` |
| 대화 | ST-03-chat (전체 화면) | 감정콩 메시지, 입력창, 전송, `< 스터디룸` |
| 쉬기 | 스터디룸이 휴식 상태로 | 쉬는 감정콩, 잠깐 쉬는 중, 다시 시작하기 |
| 나가기 | ST-03-exit (스터디룸 위 시트) | 이따 다시 할게 / 오늘은 여기까지 / 계속 공부하기 |

### ST-03-todo 지금 하는 일
- `< 스터디룸`, 할 일 + 일시, 세부 할 일 체크(완료 시 취소선)

### ST-03-chat 스터디룸 대화
- `< 스터디룸`, "이모양즈와 대화" + 할 일 이름, 채팅, 입력 "친구들에게 이야기하기" + 전송

### ST-03-exit 나가기 선택
- "잠깐 나갈까?" `이따 다시 하자 / 오늘은 그만 하자 / 계속하자`

| 누른 버튼 | 다음 화면 |
| --- | --- |
| 이따 다시 할게 | ST-04 |
| 오늘은 여기까지 | HM-01 |
| 계속 공부하기 | ST-02 복귀 |

### ST-04 다음 시작 알림
- 시트 "언제 다시 만날까?": `30분 뒤 / 1시간 뒤 / 3시간 뒤 / 직접 설정할게 > / 알림 없이 나갈게`, `저장하고 나갈게`
- 직접 설정: 날짜·시간 시트 + `이 시간에 만나`

## TK — 할 일

### TK-01 할 일 목록
- `나의 할 일` + `+`, 할 일 카드 목록, 하단 탭
- 완료한 할 일은 맨 아래(당일 것만), 체크 원 채움 + 취소선
- 길게 누르면 순서 변경, 기본 순서는 등록순
- 추가·상세·수정·삭제는 HM-02/03 화면 재사용

## CH — 감정콩

### CH-01 감정콩 대화 (`양 TALK`)
- 사용자 말풍선 오른쪽, 캐릭터는 프로필 + 이름 + 말풍선
- 입력: "친구들에게 이야기하기" + 전송
- 우측 상단 아이콘 → 대화할 친구 팝오버(화남이·기쁨이·슬픔이 ON/OFF)

## MY — 내 정보

### MY-01 내 정보
- 프로필 이미지, 닉네임 `>`, `@아이디`
- `알림 설정` 토글
